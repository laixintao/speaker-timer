# Speaker Timer 1.0.0

Speaker Timer is a native macOS presentation timer designed to stay visible without taking focus from full-screen slides.

## Highlights

- Build reusable presentation plans with named, timed sections.
- See elapsed time, the current section, the next checkpoint, and proportional progress at a glance.
- Keep the click-through timer above full-screen presentation apps on the presenter display.
- Get a visual and optional sound cue at each checkpoint.
- Pause, resume, reset, resize, and continue counting into overtime.
- Choose from Frosted Dark, Black, Cream, and Blue themes.

## Install

Download **Speaker-Timer-1.0.0-universal.dmg**, open it, and drag Speaker Timer into Applications. The ZIP contains the same universal application for Apple Silicon and Intel Macs.

- Requires macOS 14 Sonoma or later.
- Ad-hoc signed and not Apple-notarized. If macOS blocks the first launch, use **System Settings → Privacy & Security → Open Anyway** for an app you trust.
- SHA-256 checksums are provided in `SHA256SUMS`.
- Build provenance can be verified with `gh attestation verify Speaker-Timer-1.0.0-universal.dmg --repo laixintao/speaker-timer`.
